# SQL Portfolio Analytics

## Overview

This repository contains SQL analytics projects completed using Google BigQuery public datasets.

The projects demonstrate advanced SQL skills including:

- Joins
- Aggregations
- CTEs (Common Table Expressions)
- Window Functions
- Ranking Functions
- Statistical Analysis
- Business Intelligence Reporting

---

## Projects

### 1. Fintech & Web3 Analytics

- Network Congestion Analysis
- Whale Wallet Segmentation
- Daily Top-Value Transfers
- Rolling Cost Forecast

### 2. Healthcare Analytics

- Hospital Cost Markup Analysis
- Geographic Price Variance
- Statistical Outlier Detection
- Cross-Domain Analysis

### 3. Supply Chain & Maritime Logistics

- Global Port Capacity Audit
- Infrastructure Vulnerability Profiling
- Regional Logistics Gateway Ranking
- Supply Chain Rerouting Optimization

---

## Business Insights Summary

| Project | Key Insight |
|----------|-------------|
| Fintech | High transaction volume increases gas fees |
| Fintech | Whale wallets control a large share of transaction value |
| Healthcare | Healthcare costs vary significantly across states |
| Healthcare | Some hospitals are pricing outliers |
| Supply Chain | Large ports serve as major logistics hubs |
| Supply Chain | Alternative ports improve supply chain resilience |
