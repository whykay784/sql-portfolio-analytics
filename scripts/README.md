# 🏦 Project 1: Fintech & Web3 Analytics

## Problem Statement

Blockchain networks process millions of transactions daily, making it difficult to monitor congestion, identify high-value wallet activity, and understand transaction trends.

## Objectives

* Analyze transaction volume
* Detect whale wallets
* Monitor congestion trends
* Generate business insights

## Methodology

* Data extraction from Google BigQuery Public Ethereum dataset
* Data aggregation with GROUP BY
* Ranking using Window Functions
* Trend analysis using DATE functions

## SQL Skills Used

* GROUP BY
* ORDER BY
* CTEs
* Window Functions
* Aggregate Functions

## Results

* Peak transaction periods were identified.
* Whale wallets controlled a significant percentage of transaction value.
* Daily trends showed congestion periods.

## Business Insight

Monitoring whale activity and transaction volume helps investors and blockchain analysts optimize transaction timing and understand network behavior.

# 🏥 Project 2: Healthcare Analytics

## Problem Statement

Healthcare providers charge significantly different prices for similar procedures, creating pricing inconsistencies across regions.

## Objectives

* Compare provider charges
* Detect pricing outliers
* Analyze regional healthcare costs

## Methodology

Cost aggregation, ranking functions, statistical comparison, and geographic analysis.

## SQL Skills Used

* SUM()
* AVG()
* RANK()
* CASE
* Window Functions

## Results

* Significant cost variation exists across providers.
* Pricing outliers were successfully identified.

## Business Insight

Healthcare organizations can improve transparency and reduce pricing inconsistencies through data-driven monitoring.

# 🚢 Project 3: Supply Chain & Maritime Logistics

## Problem Statement

Global supply chains depend heavily on port infrastructure. Identifying logistics bottlenecks helps improve resilience and transportation planning.

## Objectives

* Analyze port distribution
* Rank countries by port availability
* Identify infrastructure risks

## Methodology

Aggregation, ranking, classification, and logistics analysis.

## SQL Skills Used

* JOIN
* GROUP BY
* COUNT()
* CASE
* Window Functions

## Results

* Countries with the highest number of ports were identified.
* Infrastructure limitations and logistics risks were highlighted.

## Business Insight

Alternative logistics routes can improve supply chain resilience and reduce transportation risk.
